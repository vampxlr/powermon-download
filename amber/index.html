How it works

How can it know how many watts one app uses?

Windows has no per-app watt meter, so PowerMon measures the totals (the battery driver and the processor's own energy counters) and splits the power above the idle floor between apps by their CPU cycles, GPU time and disk activity. It is the same idea Windows uses internally.

An app's number answers "how much would I save by stopping this?". The screen, Wi-Fi and the idle floor are shown separately, because no single app owns them. While plugged in, the total is an estimate.

Does it work on a desktop PC?

Yes, for per-app power and process details. Battery health, time left and battery history need a battery, so they stay empty. Windows "Power mode" only applies while the Balanced power plan is active.
