What it does

Windows tells you the battery is draining. PowerMon tells you why, and what you would save by stopping it.

See where the power goes

  • Live whole-laptop draw in watts, battery %, time left or time to full, and a 5-minute graph.
  • Breakdown by processor, graphics, memory, display and other hardware, and the idle floor.
  • Every app and background process ranked by estimated watts, with CPU, GPU, disk, memory and energy used today.

Understand every process

  • Plain-English descriptions for about 130 common Windows, driver and app processes, with a "safe to end?" rating.
  • Digital-signature check, publisher, file path, which services run inside each svchost.exe, network connections, and whether it starts at sign-in.
  • Optional "Ask AI" for anything else, using your own Claude API key. Off by default.

Save power in one click

  • Efficiency mode (like Task Manager), lower priority, limit CPU cores, pause and resume, or end.
  • Windows power mode, Turbo Boost on battery, and automatic switching when you plug in or unplug.
  • Rules such as "if a background app uses more than 3 W for 60 s on battery, switch it to efficiency mode". Core Windows processes are never touched.

Battery health and widgets

  • Battery health against design capacity, voltage and cycle count when the firmware reports them.
  • 24-hour charge and power history, and "what used the battery today".
  • A taskbar widget next to the clock, a floating widget, and a tray icon that shows live watts.

Questions

How can it know how many watts one app uses?

Windows has no per-app watt meter, so PowerMon measures the totals (the battery driver and the processor's own energy counters) and splits the power above the idle floor between apps by their CPU cycles, GPU time and disk activity. It is the same idea Windows uses internally.

An app's number answers "how much would I save by stopping this?". The screen, Wi-Fi and the idle floor are shown separately, because no single app owns them. While plugged in, the total is an estimate.

Does it send my data anywhere?

No. Everything is measured and stored on your PC, in %LOCALAPPDATA%\PowerMon, for 60 days. The only thing that ever leaves your PC is the optional "Ask AI" feature, and only when you turn it on with your own API key and ask it something.

Will it drain the battery itself?

It is built not to. It runs in Windows' efficiency mode while its window is hidden, samples less often in the background, and never polls the NVIDIA GPU (which would wake it up).

How do I start it with Windows, or remove it?

Turn on Settings › Start with Windows in the app. Closing the window keeps PowerMon in the tray; choose Exit from the tray menu to quit.

To remove it: turn off "Start with Windows", exit it, delete PowerMon.exe, and delete the %LOCALAPPDATA%\PowerMon folder.

Why Windows 11 only?

PowerMon relies on Windows 11's efficiency mode for apps, its energy meter counters and its taskbar layout for the widget. Rather than half-work on Windows 10, it says so and closes.
